# F8Goals — 双击 F10 呼出的极简全屏目标管理

打字即新建，回车即创建，点方块即完成。全屏大字，只有目标本身，没有多余 UI。

## 操作

| 操作 | 效果 |
|---|---|
| **双击 F10** | 呼出全屏覆盖层（目标文字从输入栏位置向上生长 + 窗口淡入） |
| **单击 F10 / Esc** | 收起，切回之前正在做的事（0.24s 渐隐） |
| 直接打字 + 回车 | 新建目标：文字从输入栏位置向上生长到列表底部（旧的依次往上顶） |
| 点击方块 | 勾选完成：目标上浮到顶部并 2s 渐隐至消失（无删除线）；淡出中再点 = 撤销 |
| 点击目标文字 | 行内编辑（回车保存；清空后回车 = 删除该目标） |
| Esc | 一级：取消编辑 / 清空草稿；二级：收起覆盖层 |
| 菜单栏图标 | 显示/隐藏、退出 |

双击判定窗口 0.45s；可见状态下单击 F7 立即收起。数据实时写入
`~/Library/Application Support/F8Goals/goals.json`（已勾选目标保留在文件里留档）。

## 布局与动画

- **输入栏固定在屏幕正中**，目标从输入栏上方往上累积（旧的在上面、新的紧贴输入栏下方）。
  上方文字填满上半屏后，输入栏随内容往下移，列表继续生长。
- **呼出**：窗口 0.4s 淡入（背景不缩放）；每条目标文字从**输入栏的位置**以 0.4 倍小尺寸、
  半透明状态出发，0.55s easeOut 向上生长到自己的列表位置，从最新一条开始逐行错峰（每行 +0.07s）。
- **新建**：回车后新目标从输入栏位置向上生长到列表底部，旧目标平滑上移。
- **勾选**：目标上浮到列表顶部 + 2s easeIn 渐隐到看不见，然后从列表移除（JSON 保留）。
- **收起**：0.24s 快速渐隐，完成后窗口 orderOut，焦点自动还给之前的应用。

## 前提与自启

- 系统设置 → 键盘 → **「将 F1、F2 等键用作标准功能键」需开启**，否则 F10 是媒体键，热键不生效。
  选 F10 是因为 Firefox（F7 光标浏览）、VS Code（F8/F9/F12）、Excel（F9 重算/F4 绝对引用）均无冲突；
  想换别的键改 `Sources/F8Goals/HotkeyManager.swift` 里的 `kVK_F10` 即可。
- 开机自启：系统设置 → 通用 → 登录项 → 添加 `dist/F8Goals.app`。
- 退出：菜单栏图标 → 退出 F8Goals（无 Dock 图标）。

## 构建

```bash
swift build -c release        # SwiftPM，无需 Xcode
./Packaging/package.sh        # → dist/F8Goals.app（ad-hoc 签名）
open dist/F8Goals.app
```

调试入口：`dist/F8Goals.app/Contents/MacOS/F8Goals --show` / `--hide`（启动后自动呼出/收起）。

## 设计要点

- **全局热键**：Carbon `RegisterEventHotKey(kVK_F7)`，无需辅助功能/输入监控权限。
- **覆盖层**：无边框窗口 + `.screenSaver` 层级 + 跨 Space，遮住菜单栏与所有应用，不打断底层 App。
- **文字动画**：行级 `@State` + `onChange(of: animatedIn)` 驱动，每次呼出都会重新播放；锚点用 `GeometryReader` 按行位置计算，文字从屏幕中心"长出来"。
- **多屏**：每个屏幕各建一块覆盖窗口。
- 技术栈：SwiftUI 内容 + AppKit 窗口壳，SwiftPM 可执行目标，LSUIElement 后台常驻。
